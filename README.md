# Business Analyst Project – Real Estate Regression Analysis

## Overview

This project analyzes a real estate dataset to identify the key factors influencing property prices using regression techniques. The goal is to generate actionable insights that can assist stakeholders in pricing strategies and investment decisions.

##  Tools & Technologies

- 🐍 Python (Google Colab)
- 📊 Pandas, NumPy, Seaborn, Matplotlib, Scikit-learn
- 💻 VSCode
- 🧮 Linear & Multiple Regression
- 📈 Power BI (for visualization, if applicable)



##  Key Tasks

- Data cleaning and preprocessing
- Exploratory data analysis (EDA)
- Regression modeling (simple, multiple)
- Model evaluation (R², RMSE)
- Insight generation

##  Results

Key predictors of housing prices identified include:
- Square footage
- Number of bedrooms/bathrooms
- Location-based variables
- Year built, etc.

More details are available in the report.
